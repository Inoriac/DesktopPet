# 形象表现层解耦审查

状态：代码审查与本轮相关回归完成。全项目构建通过；全量测试 45/47，独立失败及实际窗口验收边界见[实现总结](形象表现层-桌面端-impl-summary.md)。

## 重点检查

- 中性契约和工具没有骨骼、OpenGL、具体播放器依赖；现有生产调用实际经过契约。
- 用户配置的状态与候选可执行，状态名称和情绪/交互映射没有隐藏在主体硬编码中。
- 状态查询反映实际播放，接受、开始、完成、取消和失败语义一致；失效资源不污染原状态。
- 循环边界、过渡保护和取消/到期都有有限退出条件，单次轮次信号不重复触发自动跳转。
- 隐藏停止请求、状态推进和渲染，复位自定义初态；旧回调不会影响重新显示后的状态。
- 拖动移动独立，附加姿态不强行突破保护；触摸事实与动画是否可播放分离。
- QObject 生命周期和工具线程访问正确，无 raw backend 悬垂指针或 GUI 互等。
- 形象说明和当前状态进入模型上下文，身份/人格/记忆不因显隐重置。
- 主程序和新增/现有测试经过实际构建验证；区分基线问题、环境限制和本次回归。

## 已修复的审查发现

- 活动请求 TTL 到期或取消会打断受保护过渡：现在完成已进入的整条有限路径、放弃旧目标；后端轮次失联采用独立故障超时。
- 同步事件观察者隐藏窗口会在推进中清空活动请求：补充代次／请求有效性检查，覆盖 started、stateChanged 与 expired 回调。
- AI 禁用动作被错误应用于用户交互：模型策略与全局禁用分开；本地用户仍受状态规则约束。
- 旧工具别名参数不兼容：保留 `request_idle_transition.target_action`，同时校验旧入口的 AI 策略。
- 情绪队列上限被绕过：继续应用已有 expressionQueueLimit。
- 初态和 via 可绕过状态禁用：禁用初态给出配置诊断；包含禁用中间状态的请求在进入路径前拒绝。已进入的路径仍按保护规则收尾。
- 通用自动转换遗漏：支持 `fromState: "*"` 的自动边，具体来源优先，同目标具体边覆盖通用边；重复轮次事件不重放。
- 旧播放器自动跳转／强制拖动会绕过统一规则：生产播放器使用托管模式；拖动位置独立，附加动画走配置语义。
- JSON 类型异常可能绕过中性验证导致原生导入器抛异常：加入导入诊断并保留可用性反馈。
- 播放器测试依赖缺失外部模型：替换为确定性骨骼和关键帧夹具，实际测试 AnimationPlayer → 3D 适配器。
- 看门狗未考虑慢速／低帧率配置：时限根据资源时长、播放速率和余量计算；保留非托管模式的候选权重。
- 运行时更换形象与 GL 重建边界：锁定已选择形象；允许同一资产随 GL 上下文恢复，隐藏也不能换形象。
