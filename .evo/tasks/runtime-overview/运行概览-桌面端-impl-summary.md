## 交付结果

Launcher 左侧增加“运行概览”，查看“宠物”页所选角色的用量与运行状态。首屏包含心情、心境、活跃度、情绪强度、忙闲/排队、AI、自主活动、任务、在线时长及触摸次数；用量可切换今天、本次运行和累计。下方提供最近 7 日用量、累计模型用途/模型分组、最近 200 次调用的筛选与分页，以及角色日志目录和本次核心日志入口。

页面可见且所选角色通过本 Launcher 连接时，每 2 秒读取已有状态，隐藏时停止轮询。查看概览不会调用模型、改变情绪或触发自主活动；用户发送、停止和历史查询优先。断线后保留已知统计并标记非实时，心情/活动和本次运行不可用；离线“今天”按本机当前日期重算。旧核心不支持查询时提示升级并停止重复请求。

复用了原 StatisticManager 和异步日志队列。统计改用角色 UUID 隔离，重试、fallback、结构修复分别计数，取消与失败区分，未返回 usage 与真实零消耗区分；Anthropic 输入包含缓存读取/写入，取消或中断保留已报告用量。统计保存失败、损坏或同角色写锁冲突可见；旧累计仅在归属明确时迁入，旧文件保留。详细 AI 日志按角色存放，默认单文件 8 MiB、保留 3 个备份。

没有新增第三方依赖、数据库表、外部监控服务或模型调用。展示的情绪和运行属性均来自现有系统，不新增不存在的精力/饥饿等属性。统计展示 token，不估算费用；缺 usage 或异常退出仍可能造成缺失，不能代替供应商账单。

## 使用与交接

更新 Launcher 时应同时重建 C++ 核心。统计位于 AppData 的 `profiles/<UUID>/statistics.json`，详细日志在同目录的 `logs/`。正常退出和每 10 秒保存统计，日汇总保留 90 天、近期调用保留 200 条，累计持续保留。

[验收文档](运行概览-验收.md) 已列出 Windows 100%/150% 缩放、真实模型 usage 对照、日常自主活动、重启/改名/多角色及日志检查步骤；这些实机结果尚未标记通过。功能设计无偏差，后续按该文档验收并记录问题即可。
