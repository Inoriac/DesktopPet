# MCP 笔记搜索声明示例

这是一个假设笔记服务的声明示例，search_notes 不是对任意 MCP 服务都成立的标准工具名。实际接入时，作者必须替换为目标服务确实公开的工具及含义。

## 适用场景与准备

使用 `example.notes/search` 查询使用者已配置服务中的笔记。准备 notesConnection 所引用的服务连接，完成其要求的登录或授权。

缺少连接或服务离线属于当前不可用。服务没有公开声明的工具、实际参数与说明不一致时，应修正绑定与说明，不能猜另一个工具替代。

## 操作流程

1. 加载能力说明后，读取指定服务中 search_notes 的公开参数定义。
2. 根据使用者的搜索意图组织参数；本例假设其接受 `{"query":"会议安排"}`。
3. 只有实际参数定义支持这个输入时才调用，并按服务公开的结果结构解释返回内容。

parameters.source=mcp 用来避免重复维护服务已经提供的参数 Schema；它不意味着可以跳过参数检查或让模型编造参数。

## 结果与影响

正常返回代表搜索完成。空结果不等于服务不可用，服务错误也不等于没有匹配项。本例不包含仅受理阶段。

操作只读取搜索结果，不修改笔记；搜索词会发给所配置服务。使用者切换服务后，应确认新服务仍符合这些约定。
