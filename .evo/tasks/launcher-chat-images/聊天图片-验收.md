# 聊天图片验收

日期：2026-10-18；环境：macOS，Qt 6.8.3 C++ / PySide6 6.7.3 Launcher。

## 已完成
- 选图、粘贴截图、拖入本地图片；预览/移除；纯图和图文消息，每条最多 4 张。
- 发送版本最长边 2048、每张最多 2 MiB；原文件最多 20 MiB / 4000 万像素。支持自动旋转、透明度和 Retina 显示。
- 后台复制并保存图片，原文件删除不影响历史；SQLite/JSONL、上滑分页和文字搜索定位可返回附件。
- Vision 观察后由原主体聊天；图片观察有来源标记，不参与本地命令关键词判断，不冒充原文写入记忆。
- 失败/断线保留草稿，重试带原图片；停止沿用原有取消及队列规则；同角色重连保留附件，角色切换清理旧草稿。

## 复现界面验收

仓库根目录运行（使用已安装 Launcher 依赖的 Python）：

```sh
QT_QPA_PLATFORM=offscreen launcher/.venv/bin/python -m unittest discover -s tests -p 'test_launcher_chat*.py'
QT_QPA_PLATFORM=offscreen launcher/.venv/bin/python .evo/tasks/launcher-chat-images/visual-qa/render_images.py
QT_QPA_PLATFORM=cocoa launcher/.venv/bin/python .evo/tasks/launcher-chat-images/visual-qa/render_images.py --native
```

最后一条仅用于 macOS 原生窗口。合成脚本使用临时图片和假服务，替换 Launcher 进程跟踪，不启动桌宠或真实模型，也不修改个人历史。截图和执行记录保存在 [visual-qa](visual-qa/)。
