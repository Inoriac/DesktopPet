# 聊天图片实现审查

## §3.2 后端

已逐项检查改动：
- 图片由认证本机管道传路径，后台限量读取并保存到 UUID 命名的角色目录；普通文件、JPEG/PNG、大小和当前角色读取边界都有检查。失败只清理本次新建副本。
- 纯图片保留空原文，JSONL/SQLite、分页、最近快照均按附件判断可见；重复接受校验正文和附件，旧记录默认空附件。
- 保存成功才回送图片消息应答；导入时角色切换不会把完成结果插入新角色。后续主体不可用时生成可重试失败状态。
- Vision 读取在独立串行工作线程，沿用可取消句柄与 generation；同步完成不覆盖后续 Dialogue 句柄。
- 图中文字不会触发本地命令/复杂任务关键词路由。UserMessageReceived 与记忆提取使用用户原文，观察有明确来源标记。
- 图片重试带回原附件；文本合批与原路由保留。图片独立成批，停止和失败后的队列行为沿用原规则。
