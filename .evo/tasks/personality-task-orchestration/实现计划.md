# 性格演化与任务编排实现计划

依据：`性格演化与任务编排-桌面端-初步设计.md`。环境：Windows、Qt 6、C++20、Python launcher。

1. 扩展身份状态：七维人格、四维关系、来源去重、时间与变化限幅、参数和表达摘要的原子版本发布。
2. 实现独立任务状态机与 SQLite 检查点：受理、规划、工具、观察、验证、重规划，累计预算、停止、暂停和显式恢复。
3. 增加模型角色和睡眠人格巩固阶段：固定材料截止位置，模型提案、本地评估、最终参数摘要、取消代次与版本检查。
4. 生产接入：复杂请求路由、受限异步工具执行、任务进度和继续/停止、任务事实经历与私密感受的幂等补齐。
5. Windows 验证：新状态机和证据契约测试、现有身份/睡眠/模型/聊天回归、桌宠编译、launcher 测试。

关键约束：普通聊天保留现有路径；任务人格快照固定；用户交互优先取消未提交巩固；暂停不生成终结经历；恢复不重置预算或重放不明动作；私密存储不可用时保留待处理状态。

执行状态：以上 5 项已完成首版实现，Windows 桌宠构建、8 组 C++ 测试及 56 项 Python 测试通过。实际模型 API、生产加密依赖与桌宠窗口端到端验证尚未进行，详见同目录 [实现总结](实现总结.md)。
