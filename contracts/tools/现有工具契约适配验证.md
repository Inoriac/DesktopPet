# 现有工具契约适配验证

更新：2026-10-19。本文描述当前实现，替代 2026-10-15 的接入前盘点；早期结论可从 Git 历史查看。契约与配置入口见 [README](./README.md) 和 [插件运行时接入](./插件运行时接入.md)。

## 当前结论

通用插件链路已支持 Plugin/Skill/Tool 声明、摘要发现、按需加载、配置与权限检查、command 和 stdio MCP 执行。添加符合契约的外部能力不需要按软件名称修改主体。普通聊天与自主活动仍分别受对应权限控制。

内部工具继续提供原有功能，不要求使用者先安装插件。外部 Skill 与内部 SkillStore 的经验工作流是两个不同入口：前者加载方法正文和工具依赖，后者管理学习得到的步骤与结果记录。

## 已有能力的接入状态

[PetWindow](../../ui/petwindow_ai.cpp) 提供 46 个内部注册入口，实际注册取决于功能配置和形象桥接是否可用。文件访问等宿主能力由 [ToolRegistry](../../core/ai/tool_registry.cpp) 的元数据和工厂进入工具运行时；外部能力由 [PluginRuntime](../../core/ai/plugin/plugin_runtime.cpp) 进入统一执行器。

| 范围 | 当前状态与边界 |
| --- | --- |
| 陪伴、记忆整理、经验工作流、提醒 | 保留内部工具及原有数据服务，不把数据库或 C++ 指针作为插件配置。需要外部开放时再设计对应操作。 |
| 环境、文件/命令、天气/节日/简报 | 内部工具可继续使用。文件根目录和程序白名单仍由宿主限制；它们不是自动生成的外部能力包。 |
| 原生网页与网页插件 | 原生 `web_search` 保留 query/max_results 参数，results 从格式化字符串改为 title/url/snippet 数组；`web_fetch` 保留 url/timeout_ms 并增加 cursor，content 从原始 HTML 改为分页正文。[plugins/web](../../plugins/web/README.md) 通过共享后端提供独立 command 包供网关和自主活动使用，不新增原生工具自主旁路。消费旧结果的工作流需调整；配置与最终验收见[验证备注](../../plugins/web/验证备注.md)。 |
| 形象 | 通过形象接口执行；排队、开始和完成的语义仍由形象状态定义。没有可用形象时不凭空提供操作。 |
| 原生音乐工具 | 保留 12 个入口；状态与歌词查询不启动播放器，HTTP 操作失败不自动重试。需要启动时显式调用 lx_music_launch。 |
| LX Music 外部插件 | [plugins/lx-music](../../plugins/lx-music/README.md) 已交付一个 Tool、一个 Skill、12 项操作、适配脚本和角色配置助手。经宿主完成发现、加载和调用；真实 Windows 播放器仍待实测。 |
| 外部聊天 | [受控聊天插件](./examples/controlled-chat/README.md) 验证观察、人物识别、读取、发送回执和活动恢复。[QQ 插件](../../plugins/qq/README.md) 已实现 OneBot 后台接入并使用本地假服务验证；真实 QQ 登录、连通、收发与 Windows 实机仍由[验收交接](../../plugins/qq/验收交接.md)安排，不属于受控测试通过范围。 |
| B 站内容阅读 | [plugins/bilibili](../../plugins/bilibili/README.md) 提供搜索、评论、字幕分页与可选本地 ASR，复用已有自主活动选择；已验证匿名查询与受控完整网关，真实账号字幕/音频和 Windows 仍需实机验收。 |
| stdio MCP | [CapabilityExecutor](../../core/ai/plugin/capability_executor.cpp) 经 [McpClient](../../core/ai/mcp/mcp_client.cpp) 完成初始化、枚举与调用。未使用的 McpToolAdapter 原型已删除。 |

## 已落地的宿主责任

- Plugin、Skill 和 Tool 使用各自 Schema，检查类型、身份、引用及版本；冲突明确报错。
- 发现只提供摘要；加载 Skill 不执行方法，也不全量注入所有依赖 Tool 的参数。
- 内部工具使用注册元数据与执行工厂；外部工具按声明绑定程序、参数、配置或 MCP 连接。
- 调用前检查当前上下文授权、参数、对象/路径范围。宿主支持的 Schema 范围及配置详见运行时接入文档。
- command 输入输出和 MCP 结果按契约处理；业务返回由结果适配器区分 completed、accepted、unknown 等状态。未确认的副作用不自动重放。
- 更新、禁用和卸载会使后续发现和调用依据当前配置、版本与权限判断。

## 使用结果的边界

| 情况 | 应如何解释 |
| --- | --- |
| 通知回调排队 | 只说明提交了展示请求，不证明用户看见。 |
| 提醒创建成功 | 说明记录建立；未来是否送达要看实际触发结果。 |
| 形象动作 queued / started | 不代表整段动画已经播放完。 |
| 环境查询 supported=false、简报 weather_error | 可以是查询完成但平台不支持或部分数据缺失。 |
| 音乐 HTTP 响应失败 | 操作可能已经生效；先核对当前状态，不直接重复切歌。 |
| 包已加载 | 不证明软件已安装、账号已登录或业务执行成功。 |
| 网页 status / command 退出码 0 | status 不联网；退出码 0 只代表协议正常，业务成功查看 state=completed。失败保留具体 code/message。 |
| 网页搜索摘要 / 正文分页 | 摘要不等于全文，hasMore=true 表示仍有后续文字；续读保持第一次输入 URL，最终来源链接不截短。 |

## 可重复验证

[verify_contract.py](./verify_contract.py) 2026-10-19 上次复验为 **96/96**，包含声明正反例、Plugin/Skill/Tool、观察源、参考脚本、临时 Git、SQLite 歌单和受控聊天；命令与依赖版本见 [README](./README.md)。该脚本不连接真实 MCP 或播放器，不代表新网页插件已完成验收。

宿主行为由 CTest 覆盖：PluginRuntimeTests 检查加载、权限、command、受控 stdio MCP 及插件管理；LxMusicPluginTests / LxMusicAdapterTests / LxMusicConfigureTests 检查音乐包的配置与完整调用；NativeMusicTests 检查原生音乐请求错误与单次发送；AutonomousChatTests 等覆盖聊天与自主活动链路。所有外部交互使用临时服务和数据。

BilibiliAdapterTests / BilibiliTranscriptionTests / BilibiliSetupTests / BilibiliConfigureTests 覆盖本包 Python 行为；BilibiliPluginTests 使用实际配置器和 PluginRuntime，AutonomousChatTests 使用实际 AIBrain 验证选择阅读、wait 和全局关闭自主。插件没有新增主系统生产分支，也没有新建自己的调度器。

网页共享后端阶段已完成 macOS 构建、72/72 CTest 与真实公开搜索/正文/续读烟测。后续用户要求延后测试：`WebCommandTests` 已编译但最终实现未运行；角色配置、失败 data 通过普通模型清洗路径、实际网关、自主使用和 Windows 仍待按[验证备注](../../plugins/web/验证备注.md)验收。本包尚未新增专用网关/自主自动化用例，不将旧测试通过视为新包通过。

已有 macOS 自动化结果不等于真实 Windows 桌面、播放器、音频设备或 QQ 的验收；这些外部条件仍需在相应环境验证。项目 CR 记录见 [review.md](../../.evo/tasks/project-cr/review.md)。
